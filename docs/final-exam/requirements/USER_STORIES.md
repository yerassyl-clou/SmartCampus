# User stories

| Story | Acceptance case |
|---|---|
| V2-US02 private profile | Owner sees only own profile and cannot update admin fields. |
| V2-US03 private courses | Owner sees only enrolled/cross-linked own courses. |
| V2-US04 private documents | Owner upload/read is isolated by owner key. |
| V2-US06 deadlines | Deadline access matches owner and course. |
| V2-US07 chat | Retrieval is owner/course scoped and quota bounded. |
| V2-US09 analytics | Metrics exclude unverified real counts and disclose unknown values. |
